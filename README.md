## Zane Neave

ML researcher and engineer (MSc AI, First Class Hons) working on efficient deep learning KV-cache compression, quantization and efficient LLM inference. I care about the research questions *and* whether the answer survives contact with real hardware.

By day: perception and autonomy at **Syos Aerospace** real-time models on Jetson / TensorRT in production. Alongside that, going deeper into research on efficient inference and contributing across the open-source ML ecosystem.

<br/>

**Open source** — device-agnostic (Apple Silicon / MPS / CPU) fixes, model support, and KV-cache tooling. &nbsp;[**all open PRs →**](https://github.com/pulls?q=is%3Apr+author%3Axquantize+is%3Aopen)
