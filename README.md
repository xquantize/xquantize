### `~/about`

ML **researcher** and engineer (MSc AI, First Class Hons) working on **efficient deep learning** KV-cache compression, quantization, and efficient LLM inference. I care about the research questions *and* whether the answer survives contact with real hardware.

By day: perception & autonomy at **Syos Aerospace** — real-time models on Jetson / TensorRT in demanding production environments. Alongside that I'm going deeper into research on efficient inference and contributing across the open-source ML ecosystem.

> Models that work outside the datacenter · honest benchmarking on real hardware · reproducible research.
